answer: "macOS kann einen Ordner nicht direkt mit einem Passwort versehen. Öffnen Sie das Festplattendienstprogramm, wählen Sie Ablage > Neues Image > Image aus Ordner, stellen Sie die Verschlüsselung auf 256-Bit-AES und das Format auf Lesen/Schreiben und sichern Sie das Image. ## Grenzen und Risiken

- **Passwort weg, Daten weg.** Auch Apple kann ein Image nicht entsperren.
- **Geöffnet heißt lesbar.** Solange das Image eingebunden ist, kann jeder an Ihrem angemeldeten Mac die Dateien lesen.
- **Das Original bleibt unverschlüsselt**, bis Sie es löschen. FileVault schützt die gesamte Festplatte.
