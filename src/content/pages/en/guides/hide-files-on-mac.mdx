## Limits and risks

Every method on this page except the encrypted image is *obscurity*, not security.

- **⌘⇧. reveals everything.** It works in Finder and in the Open and Save dialogs of most apps, so anyone sitting at your unlocked Mac can see hidden items in a few seconds.
- **Terminal shows them too.** `ls -a` lists dot-prefixed items, and `ls -lO` also shows the `hidden` flag.
- **Backups copy them.** Time Machine and cloud backup tools treat hidden files like any other file.
- **Some apps ignore the flag.** An app's own recent-files list can still mention a hidden file by name.

<Callout type="warning">If you only need to stop yourself or family members from stumbling on a folder, hiding is enough. If the files would hurt you if someone read them, use encryption.</Callout>
