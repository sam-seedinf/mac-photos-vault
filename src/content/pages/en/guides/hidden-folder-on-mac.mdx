## Limits and risks

- A hidden folder is still an ordinary folder. Anyone who runs `ls -a`, uses ⇧⌘G with the right path, or presses ⌘⇧. can open it.
- Spotlight, backups and some apps' recent-files lists may still reveal names or contents. Test by searching for a file inside the folder.
- Nothing is encrypted. If the Mac is lost and FileVault is off, the files are readable from the disk.

<Callout type="tip">Pair a hidden folder with an encrypted disk image if the contents matter. Hiding keeps it out of sight; encryption keeps it unreadable.</Callout>
